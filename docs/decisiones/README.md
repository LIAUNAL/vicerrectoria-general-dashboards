# Registro de decisiones

Las decisiones que moldearon este repositorio, con el hecho que las obligó.

Están aquí porque todas nacen de una tensión real entre fuentes o plataformas,
y porque la razón se olvida mucho antes que el código.

| # | Decisión | Qué resuelve |
|---|---|---|
| [001](001-dos-capas-paca-y-pages.md) | Dos capas sobre un único archivo de datos | Paca no puede desplegarse en GitHub Pages |

## Criterio común

Ninguna discrepancia entre fuentes se resuelve en silencio. Cuando dos
documentos oficiales dicen cosas distintas, el tablero publica ambas y marca la
diferencia como hallazgo: elegir una por cuenta propia sustituiría la evidencia
por una interpretación, y eso le corresponde a la supervisión.
